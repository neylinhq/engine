# Маршрутизация ввода

Компонент преобразует снимок состояния ввода `Snapshot` в действия `Actions`
для камеры и приложения. Он не зависит от GLFW или ImGui. Захват курсора,
видимость панелей и владение клавиатурой представлены раздельно.

`poll_window` позволяет обработать F11 до получения изображения для отрисовки.
Обычный `poll` использует ту же историю нажатий, поэтому команда не выполняется
повторно. `synchronize` согласует удерживаемые клавиши и кнопки с текущим
состоянием; `rebase_pointer` сбрасывает базовую позицию для дельт мыши.

Захват курсора для управления камерой требует нового нажатия вне UI.
Нажатие, включившее захват, не передаётся инструментам до
отпускания обеих кнопок редактирования. Перетаскивание удерживаемой кнопки
из UI в сцену не включает захват. Escape имеет приоритет над повторным захватом;
потеря фокуса освобождает курсор.

Координаты указателя выражаются в единицах оконной системы. Оконный компонент
считывает и сбрасывает накопленное движение колеса при создании снимка.
Снимок также передаёт нажатие Space, даже если клавишу успели отпустить.
Прыжок использует это событие, а подъём в полёте зависит от удержания клавиши.
Набор поддерживаемых приложением действий определяется обработчиком `Actions`;
наличие команды в перечислении не означает, что приложение реализует её.
