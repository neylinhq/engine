# Параллельные циклы с ограниченным числом потоков

`for_each_index` распределяет независимые индексы не более чем между восемью
потоками с обязательным ожиданием завершения. Небольшая нагрузка выполняется
в вызывающем потоке. Порядок обработки индексов не задан. Переданная в
`for_each_index` функция должна допускать одновременные вызовы из нескольких
потоков; синхронизацию доступа к общим данным обеспечивает вызывающий код.
Все рабочие потоки завершаются до возврата или передачи исключения.
