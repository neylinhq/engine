# Геометрия

`Vec3` — трёхмерный вектор с компонентами `double`; `Box` — ограничивающий
параллелепипед с гранями, параллельными осям. Компонент предоставляет векторные
операции, интерполяцию и проверку конечности координат.

Единицы координат задаёт вызывающая сторона. Типы не содержат преобразования
между метрами и вокселями, состояния процесса или операций ввода-вывода.
