# JSON-кодек настроек рендера

Читает и записывает настройки рендера и атмосферы в формате NAADF.
Sandbox использует обычный режим разбора с ограничением допустимых значений.
Benchmark использует строгий режим: неизвестные поля и значения вне диапазонов
считаются ошибками, поэтому запрошенная нагрузка не корректируется автоматически.

Сериализация сохраняет все действующие параметры. Компонент работает со строками
JSON; выбор файла и операции файловой системы выполняет приложение.
