# JSON-кодек настроек рендера

Читает и записывает настройки рендера и атмосферы в формате NAADF.
Sandbox и Benchmark загружают явно выбранные `*.settings.json` через `load`.
Неизвестные поля и недопустимые значения приводят к ошибке. Для отсутствующих
полей используются значения по умолчанию. `save` записывает действующие значения
в выбранный файл. Перед записью проверяются те же ограничения, что при загрузке.
При ошибке проверки существующий файл сохраняется.
