# Шейдеры NAADF на Slang

Компонент содержит шейдеры рендера Albedo, Base и PathTracer, генерации мира,
дедупликации блоков, правок геометрии, обновлений сущностей и построения AADF.
Алгоритмы основаны на NAADF. Точки входа компилируются отдельно; привязки ресурсов
и состав программ описаны в `resources/programs.json`.

Компиляцию задаёт `cmake/shader_entries.cmake` в корне проекта. Вместе со SPIR-V
Slang создаёт JSON с описанием типов, смещений uniform-полей и привязок ресурсов.
Матрицы хранятся по строкам; для буферов используется скалярная раскладка Vulkan.
Финальный графический проход рисует полноэкранный треугольник.

Шейдеры собираются для двух представлений чанков:

- `split`: отдельные изображения `R32_UINT` для геометрии и сущностей;
- `packed`: изображение `R32G32_UINT` с совместимым представлением `R64_UINT`
  для атомарного доступа.

Функции из файлов `chunk_read.slang`, `chunk_write.slang` и `chunk_atomic.slang` в
`resources/shaders/world/data/` изолируют различия форматов. Чтение packed
возвращает пару слов одним обращением; обновление AADF использует нативные
атомарные чтения и обмены, сохраняя слово сущностей. Split использует 32-битные
атомики геометрии. Логическая запись чанка в обоих случаях занимает восемь байт.

Рендерер выбирает представление по возможностям устройства. Требования описаны
в [документации Vulkan](../vulkan/README.md). Источник алгоритмов —
[NAADF](https://github.com/cg-tuwien/NAADF); уведомление MIT находится
в [docs/licenses/naadf.txt](../../../docs/licenses/naadf.txt).
