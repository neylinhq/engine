# Пути камеры

Путь состоит из именованных узлов с позицией, направлением и длительностью.
`Path` поддерживает замену и редактирование узлов, запуск, остановку и получение
следующего положения через `advance`.

Интерполяция NAADF использует веса пятой степени для четырёх соседних узлов;
также доступна линейная интерполяция. Скорость выводится из длительностей
участков. Недопустимые узлы отклоняются без частичного изменения пути.
Пустой путь не запускается.
