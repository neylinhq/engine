# Интерфейс Sandbox

Компонент на Dear ImGui предоставляет меню File, View и Tools, настройки рендера
и атмосферы, панели моделей, сущностей, материалов и инструментов, диагностику
и редактор пути камеры. Файловые действия оформляются как запросы, которые
обрабатывает приложение. Выбор файлов использует `std::filesystem`.

Контекстом ImGui и его кадровым циклом владеет рендерер Vulkan. Создавайте
`Frontend` после `Renderer` для того же окна. Если `Renderer::begin_frame()`
успешно вернул `true`, вызовите `Frontend::draw` для построения панелей,
затем `Renderer::draw` для отрисовки кадра.

Видимость панелей и владение вводом разделены. Приложение синхронизирует
`accept_input` при передаче курсора между сценой и UI. Видимые панели при
захваченном курсоре остаются читаемыми, но не обрабатывают наведение, нажатия,
прокрутку и текст. Передача ввода очищает очередь событий, удерживаемые кнопки
и текстовый фокус. При освобождении курсора UI получает его текущую позицию.
Системные события фокуса обрабатываются и при блокировке ввода панелей.

Каждый выбор режима рендера формирует `Operation::restart_render`, включая
повторный выбор текущего режима. Приложение передаёт запрос рендереру.
`reset_world()` сбрасывает связанные с миром действия редактора и бюджет AADF
после успешной замены сцены, сохраняя независимые настройки панелей.
