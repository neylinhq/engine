# Окно GLFW

Компонент владеет инициализацией GLFW, окном, обработкой ввода и созданием
поверхности Vulkan. Требуются GLFW 3.4 и заголовки Vulkan. Окно создаётся
без контекста OpenGL.

Безрамочный режим занимает прямоугольник одного монитора и хранит геометрию
для восстановления отдельно. Расчёт перехода выполняет `platform.window_state`.
Координаты framebuffer и рабочего стола различаются; ограничения позиционирования
Wayland возвращаются как ошибки.

Окно должно существовать до уничтожения его поверхности Vulkan и рендерера.
Инициализация GLFW глобальна для процесса; реализация рассчитана на одного
владельца `Window`. Идентификаторы мониторов стабильны на время наблюдаемого
подключения и не являются постоянными аппаратными идентификаторами.
