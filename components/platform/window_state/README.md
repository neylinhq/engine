# Состояние окна

Компонент рассчитывает переходы между оконным и безрамочным режимами в
координатах рабочего стола. Оконный адаптер применяет план и вызывает `commit`
только после успеха. Неудачный переход не меняет состояние; прямоугольник
восстановления хранится отдельно от полноэкранного.

Поля монитора `desktop_scale_x` и `desktop_scale_y` задают число единиц координат
рабочего стола на логическую единицу по каждой оси. Они не заменяют масштаб
framebuffer. Компонент не зависит от камеры, мира или API оконной системы.
