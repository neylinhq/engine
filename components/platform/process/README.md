# platform.process

Сервисы процессов для Windows и Linux. Дочерний процесс получает вектор аргументов
без оболочки. Метрики памяти относятся к текущему процессу: объём резидентной
памяти в байтах и его максимум за время жизни процесса. Объём приватной
выделенной памяти доступен в Windows, а в Linux отсутствует (`std::nullopt`).
Файлы для SHA-256 читаются порциями. В Windows хеш вычисляет CNG, в Linux
используется OpenSSL EVP.
