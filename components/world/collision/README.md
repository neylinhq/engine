# world.collision

Адаптер Neylin Physics для запросов персонажа к воксельному миру. Координаты
запросов заданы в метрах. Адаптер обходит чанки, блоки и отдельные воксели
в пределах объёма, который покрывают границы капсулы за время перемещения.
Однородные занятые узлы участвуют целиком, а пустые узлы пропускаются.
SDK выполняет непрерывную проверку перемещения капсулы и определяет
контакт при пересечении. Перед вызовом координаты переводятся в локальную
систему воксельного узла, после чего адаптер возвращает точку контакта
в координатах сцены. Запрос может
принимать фильтр контактов. Контакты, которые фильтр отклоняет, не
ограничивают поиск первого подходящего контакта.

`Terrain` заимствует `WorldView`. Представление должно оставаться
действительным на протяжении запросов. Получайте новое представление после
изменения мира. Коллизии используют зафиксированные правки вокселей.
В запросах участвует только занятая геометрия воксельного мира.

`CapsulePlacement::guard` проверяет новые воксели той же капсулой. Объект
`CapsulePlacement` должен существовать до завершения правки.
