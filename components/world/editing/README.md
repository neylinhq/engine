# world.editing

Воксельные кисти Sphere, Cube и Paint, связная заливка материала и штамповка
моделей. Публичный API находится в `include/engine/world/editing`.

Для `apply_brush` центр и радиус задаются в воксельных координатах и должны быть
конечными числами. Допустимый радиус — `(0, 400]`; нарушение этих условий вызывает
исключение. Индексы материалов относятся к реестру целевого мира.

Кисти подготавливают независимые чанки параллельно. Sphere и Cube заменяют
полностью покрытый чанк компактной однородной записью. В остальных случаях чанк
декодируется один раз и обновляется строками вокселей. Попадание в область кисти
определяется по центру вокселя. Paint меняет материал существующей геометрии,
сохраняя пустые воксели.

Изменения передаются в общее состояние мира после завершения рабочих потоков
и фиксируются через `commit_edits`. Хранением данных и журналом обновлений GPU
управляет [world.model](../model/README.md).

`stamp_model` копирует непустые воксели и не регистрирует палитру исходной модели.
Перед штамповкой загруженную модель нужно сопоставить с материалами целевого мира
через `World::add_model`. Для мира `world`, пути `path` и начала штамповки `origin`:

```cpp
const auto index = world.add_model(engine::world::storage::load(path));
engine::world::editing::stamp_model(world, world.models()[index], origin);
```

`origin` задаётся в вокселях. Часть модели за границами мира пропускается.
