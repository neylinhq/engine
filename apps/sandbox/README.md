# Sandbox

Интерактивное приложение для просмотра и редактирования воксельных сцен.
Использует компоненты Engine и интерфейс Dear ImGui. При запуске без сцены
создаёт пустой мир 256 × 256 × 256 вокселей.

## Запуск

Из корня проекта после сборки:

```powershell
.\out\windows-release\bin\sandbox.exe
.\out\windows-release\bin\sandbox.exe --scene C:\Scenes\world.cvox --voxel-size 1
.\out\windows-release\bin\sandbox.exe --help
```

В Linux исполняемый файл находится в `out/linux-release/bin/sandbox`.
Карты хранятся вне проекта. `--scene` принимает CVox, VOX, VL32, OBJ и STL
и создаёт мир по размеру импортированной модели. В интерфейсе `File > Open`
открывает CVox, а отдельные команды импорта — VOX, VL32 и сетки OBJ/STL.
`Save As` сохраняет текущий мир в CVox с подтверждением перезаписи.

`--voxel-size` задаёт размер вокселя в метрах. `--camera X,Y,Z,YAW,PITCH`
принимает позицию в метрах и углы в радианах. Например:

```powershell
.\out\windows-release\bin\sandbox.exe --scene C:\Scenes\strata-03125.cvox --voxel-size 0.03125 --camera "256,104,112,0,-0.08"
```

`--settings FILE.json` выбирает файл настроек; по умолчанию используется
`out/user/settings.json` относительно каталога запуска. Кнопка Save в Settings
записывает настройки в этот файл. Формат сохраняет имена полей NAADF.

## Управление

| Действие | Управление |
|---|---|
| Движение камеры | W / A / S / D |
| Обзор | Мышь при захваченном курсоре |
| Ускорение | Shift |
| Подъём / спуск | Space / Ctrl |
| Панели и захват курсора | Tab / F1 |
| Освободить курсор, отменить выбор материала или размещение | Esc |
| Оконный / безрамочный режим | F11 |
| Применить инструмент или подтвердить размещение сущности | Левая кнопка мыши |
| Размер кисти | Колесо мыши |
| Воспроизведение пути камеры | F2 |
| Переключение Base / PathTracer | F7 |
| Поворот солнца | Стрелки влево / вправо; Shift ускоряет |
| Приостановить сэмплирование | Удерживать P |

Камера свободно проходит через геометрию и границы мира. Правая кнопка по сцене
захватывает курсор; левая тоже включает захват, если инструмент не выбран.
Нажатие для захвата не применяет кисть. При захвате видимые панели не принимают
ввод. После освобождения курсора взаимодействие с ними возобновляется.

Инструменты действуют под свободным курсором или в центре вида при захвате.
Erase удаляет геометрию, Continuous повторяет действие кисти при удержании кнопки.
Пипетка выбирает материал геометрии при отпускании левой кнопки; сущности в этом
выборе не участвуют. Пути камеры сохраняются и загружаются в формате `.pnb`.

## Рендер и захват кадров

```powershell
.\out\windows-release\bin\sandbox.exe --scene C:\Scenes\world.cvox --width 640 --height 360 --mode albedo --frames 8 --no-ui --screenshot C:\Captures\albedo.png --validation
```

`--frames 0` означает интерактивный режим. `--screenshot` без положительного
числа кадров выполняет один кадр и завершает приложение. Кнопка снимка в UI
сохраняет только сцену; CLI захватывает итоговый кадр, включая UI, если он включён.
Каталог для снимка создаётся автоматически.

`--hidden` создаёт скрытое окно, но требует оконной системы.
`--shaders DIRECTORY` переопределяет каталог скомпилированных шейдеров, который
по умолчанию ищется рядом с исполняемым файлом.

Для диагностики доступны `--chunk-layout automatic|packed|split`,
`--frame-wait deferred|early` и `--output-path automatic|offscreen`.
Фактическое представление чанков и внутреннее разрешение рендера видны в Debug.
Требования и поведение описаны в [документации рендерера](../../components/rendering/vulkan/README.md).
Для воспроизводимых измерений используйте [Benchmark](../benchmark/README.md).
